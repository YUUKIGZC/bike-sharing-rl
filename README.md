# 基于深度强化学习的共享单车动态调度与定价策略优化

## 项目简介

本项目为本科毕业设计。

研究共享单车运营过程中存在的车辆供需不平衡问题，尝试利用深度强化学习方法，对共享单车的动态调度与动态定价策略进行优化。

项目将建立共享单车运营环境，将不同时间、不同站点的车辆数量及用户需求等信息作为状态，并通过智能体学习车辆调度和价格调整策略。

## 研究内容

- 共享单车运营数据的整理与分析
- 共享单车动态调度环境建模
- 马尔可夫决策过程（MDP）建模
- 基于深度强化学习的调度策略
- 动态定价策略
- 调度与定价联合优化
- 不同策略的实验对比
- 数据可视化与仿真系统
